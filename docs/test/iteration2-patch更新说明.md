## iteration2 patch 更新说明

本次更新完成了 TA `Create / Edit Applicant Profile` 页面中简历相关功能的整合与优化，主要包括：

- 将原先分开的“上传简历”和“从简历自动填充档案”两个卡片合并为一个统一卡片。
- 在同一卡片内保留单一文件选择区域，并提供两个独立按钮：
  - `Save Resume`：上传并保存最新简历文件，支持 `PDF`、`DOC`、`DOCX`。
  - `Auto-Fill Fields`：根据当前档案中的 `Student ID`，到 `uploads` 目录中找到该用户最新保存的简历，提取教育背景、技能和经验，并预填充到下方可编辑档案字段中。
- 页面继续显示当前已上传简历的文件名。
- 当上传文件类型无效时，系统继续显示明确错误提示。
- 自动填充后，助教仍可在保存档案前手动检查和修改提取结果。
- 调整后避免了“保存简历”操作直接覆盖档案字段，使“保存文件”和“自动填充字段”两个操作职责更清晰。
- 同一名用户可多次点击 `Save Resume` 上传文件，但 `uploads` 目录中该用户始终只保留一份最新简历；系统会在保存前清理该用户历史上已保存的 `pdf`、`doc`、`docx` 简历文件，避免同时存在多份不同扩展名文件。
- `Save Resume` 现在只执行简历保存，不再触发解析和自动填充；`Auto-Fill Fields` 对已保存 `PDF` 文件的解析改为使用稳定的 PDF 文本提取方式，修复了自动填充时出现乱码的问题。

本次更新在保持现有页面风格基础上完成，尽量与当前系统 UI 和后端结构保持一致。
